Ocean Shader: Technical Breakdown

Compute Shader Wave Simulation, Camera Near-Plane Split View & Distance-Based Tessellation

🌊 Gerstner Waves via Compute Shader

Instead of running expensive Gerstner math per vertex in the Vertex Shader, the wave simulation is executed inside a GPU Compute Shader.

  • Outputs global Displacement Map and Normal Map RenderTextures.
  • Ocean mesh samples the global maps for vertex displacement.
  • Buoyancy C# physics system and post-processing effects read the single source of truth buffer.
  • Decouples simulation cost completely from surface geometry complexity.

✂️ Split View & Near-Plane Water Line

Switched from geometric 2-sided mesh rendering to camera near-plane clipping logic. Eliminates near-clip artifacts, avoids rendering duplicate ocean meshes with complex tessellation, and achieves a pixel-perfect waterline.

🔍 Hull / Domain Tessellation & Horizon Flattening

Implemented distance-based Hull/Domain tessellation shaders for micro-surface ripple details without performance overhead. Added horizon displacement flattening to prevent specular/depth z-buffer artifacts.
