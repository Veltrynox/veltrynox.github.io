# Media Folder

Place your video (.mp4) and image (.png, .jpg, .gif) files in this folder to include them in your portfolio.

### Suggested File Names for New Projects:
- `artstation_project_1.mp4` (or `.png`/`.gif`) -> ArtStation Project 1 (https://www.artstation.com/artwork/41bWB1)
- `artstation_project_2.mp4` (or `.png`/`.gif`) -> ArtStation Project 2 (https://www.artstation.com/artwork/bg9Zym)

Once you place your media files in this folder, you can update the source link in `index.md` or let us know!
